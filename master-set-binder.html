☁ Sync across devices

Keeps this binder's progress in a GitHub Gist so your phone and computer stay in step. Set it up once on each device using the same Gist ID. Your token is stored only in this browser — it is never written into the HTML file, so the file itself stays safe to copy, host or re-download.

Which button when: normally you need none of them — auto-push handles it and the guide pulls on load. Pull takes the cloud copy if it is newer. Push forces this device's copy up. Merge both unions the two, keeping every mark from either side — use it if you ticked cards on both devices while offline.

Worth knowing: a secret gist is unlisted, not private — anyone with the link could read it. It holds only card IDs and owned/ordered flags, no personal data. If you lose the phone, revoke the token on GitHub and the gist becomes read-only to it.

Import progress

Merge adds the file's marks to what's already here. Nothing is removed — so a card you un-marked on the other device stays marked here. Safe for combining two devices.

Replace makes this device an exact copy of the file, including un-marks and deletions. Use this when the file is your source of truth. Anything marked only on this device is lost.
